# Documentazione di BlockRock

Questa cartella contiene il materiale di supporto al progetto: loghi, diagrammi e file statici.
Per guide dettagliate e istruzioni di build consulta il [Wiki ufficiale](https://github.com/BlockRockAdmin/BlockRock/wiki).

La [visione di prodotto](visione-prodotto.md) descrive il percorso personale e
finanziario che BlockRock intende supportare.

L'[MVP Nexus](../nexus/README.md) comprende account privati, sincronizzazione,
passi quotidiani, interessi, obiettivi e backup. La guida distingue l'avvio sul
PC dall'accesso HTTPS degli altri dispositivi nella rete privata.

La [roadmap di sviluppo](roadmap.md) distingue il primo MVP completato dai
passaggi operativi e dalle integrazioni ancora da definire.

## Come contribuire
1. Leggi le linee guida in [CONTRIBUTING.md](../CONTRIBUTING.md).
2. Proponi modifiche aprendo una Pull Request.
3. Per domande o segnalazioni usa le [Issue di GitHub](https://github.com/BlockRockAdmin/BlockRock/issues).
